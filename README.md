# I Ching Transformations and Birth-Time Checks

This repository provides a machine-readable table of hexagram transformations and a practical checklist for comparing birth-time inputs.

The calculator and worked examples are available at [Clear Bazi Chart](https://clearbazichart.com/).

## Files

- `hexagram-transformations.csv` maps each hexagram to nuclear, reversed, and complementary hexagrams.
- `birth-time-checklist.md` lists the inputs and clock conventions to record when comparing charts.

## Table conventions

Bits run from bottom line to top line, with 1 for yang and 0 for yin. The nuclear hexagram uses lines 2–4 as its lower trigram and lines 3–5 as its upper trigram. Reversal changes line order, and complementation flips each line. Hexagram numbers follow the King Wen sequence. The table describes these operations and does not assert a universal naming convention across schools.

Open the CSV in a spreadsheet or load it with any CSV parser. Its transformations are reference data, not birth-chart calculations.
