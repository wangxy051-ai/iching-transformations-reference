# Birth-Time Comparison Checklist

Use this checklist when two Four Pillars tools give different results for the same recorded birth information.

1. Record the original calendar date and clock time. Mark an unknown hour as unknown.
2. Record the birthplace and the named time zone used by each tool.
3. Compare the resolved UTC instants, including the historical offset and daylight-saving treatment.
4. Record whether true solar time is enabled and the longitude used for that correction.
5. Compare the year and month boundary conventions, including solar terms.
6. Record the day rollover convention and how an unknown hour is displayed.
7. Compare the four pillars and any luck-period settings separately. Keep the inputs and settings so the comparison can be repeated.

The checklist records conventions for comparison. It does not infer a missing birth time or determine which method is correct.
